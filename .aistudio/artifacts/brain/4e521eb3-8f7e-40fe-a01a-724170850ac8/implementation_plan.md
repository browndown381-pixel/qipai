# 棋牌权威服务端架构升级实施计划

## 1. 服务端核心架构与数据流图

## 2. 已确认的核心方案决策

1. **数据持久化与金币账本安全（异步防抖原子落盘 + 金币账本流水 + 房间快照热备）**
   - **消除同步 I/O 阻塞**：将原先每次操作直接调用 `fs.writeFileSync` 升级为 **内存热读写 + 300ms 防抖异步合并落盘（Write-Behind）**，并在进程退出信号（`SIGINT` / `SIGTERM`）时触发强制同步刷盘。
   - **原子文件替换防损坏**：落盘时先写入临时文件（`.game-data.json.tmp`），写入完成后通过原子 `fs.promises.rename` 覆盖主文件，彻底杜绝异常断电或重启导致 JSON 截断损坏。
   - **金币账本审计流水（Bean Ledger）**：为每次开房消耗房卡、免费补给、对局结算建立不可篡改的账本流水记录（含 `txId`、变更前后余额、变动原因、关联 `roomId`/`matchId`、时间戳），严防负余额或重复扣款。
   - **房间快照热备（Hot Backup）**：每当房间阶段（`phase`）流转时，自动将房间摘要与关键恢复状态同步写入内存 `redisClient`（带 TTL），并在服务端提供热备查询能力。

2. **WebSocket 协议安全与防重放保护（签名会话令牌 + 令牌桶限流 + 动作序号幂等校验）**
   - **HMAC 签名会话令牌（Session Token）**：游客首次认证（`c2s_auth_guest`）成功后，服务端使用内置密钥签发绑定 `playerId` 的 `sessionToken` 返回给客户端持久化；后续连接优先校验签名令牌，防止恶意客户端随意伪造他人 `playerId` 劫持牌局。
   - **令牌桶限流器（Token Bucket Rate Limiter）**：在 `ConnectionManager` 中为每个 Socket 维护轻量级令牌桶（例如容量 25、每秒补充 12 个令牌），对高频恶意连点或脚本洪泛请求返回友好限流提示并丢弃，保护牌局主线程。
   - **动作序号与幂等校验（Action Sequence Guard）**：支持客户端在出牌、抢庄、下注、捞牌等动作载荷中附带 `actionSeq`（或由服务端按毫秒窗口对相同座位+相同阶段+相同动作做指纹去重），确保弱网重传不会触发二次扣豆或二次摸牌。

3. **房间调度与断线接管（智能真人撮合窗口 + 全游戏断线自动 AI 托管）**
   - **智能真人撮合窗口**：改进 `RoomManager.quickMatch`，在创建或加入公开房后提供智能撮合缓冲机制（优先匹配正在等待同游戏、同模式、同底分的真人房间，按需平滑分批入座 AI 机器人并支持真人优先抢占未开局席位），同时配备定时巡检器回收超时僵尸房。
   - **全游戏断线自动 AI 托管（Universal Auto-Trusteeship）**：
     - 当玩家在牌局中途断线（`handlePlayerDisconnect`）或主动开启托管（`c2s_toggle_trusteeship`）时，统一将该座位的 `trusteeship` 置为 `true`。
     - 覆盖 **斗地主、红中/普洱麻将、抢庄牛牛、炸金花、云南捞腌菜** 全部 5 款游戏：处于断线或托管状态的真人玩家轮到操作时，不再让全桌苦等 8~15 秒倒计时，而是在 **1.0s~1.2s** 内由对应游戏的 `BotEngine` 自动代为执行最优抢庄、下注、出牌或捞牌决策；玩家重连或点击取消托管后立即恢复手动控制。

## 3. 交互与可观测性体验提升

- **断线托管状态可视化与一键接管**：当玩家网络闪断重连或超时进入托管时，牌桌状态同步包含 `trusteeship` 标识，重连后发送任何有效操作即可自动解除托管，杜绝“卡死全桌”体验。
- **客户端无感升级**：`SocketClient` 自动缓存并回传服务端下发的 `sessionToken` 与递增 `actionSeq`，对现有大厅和牌桌组件完全透明。
- **服务端健康与账本审计接口**：新增轻量级 `/api/server/stats` 与 `/api/ledger/:playerId` 接口，便于实时查看当前活跃房间数、在线连接数、限流拦截统计与玩家金币流水明细。

## 4. 核心模块状态与生命周期流转映射

| 服务端子系统 | 触发条件 / 输入事件 | 权威服务端处理逻辑 | 状态输出与容错保障 |
| :--- | :--- | :--- | :--- |
| **身份认证与会话绑定** | `c2s_auth_guest` (含可选 `sessionToken`) | 校验 HMAC 令牌签名；若首次登录则生成新令牌并绑定 Socket | 下发 `s2c_auth_success` (含 `sessionToken` 与恢复房间信息) |
| **令牌桶与幂等网关** | 任意 `c2s_*` 游戏动作事件 | 1. 扣除令牌桶配额；2. 校验 `(playerId, phase, actionSeq)` 指纹 | 超频或重复包静默拦截并记录告警；合法包放行至房间实例 |
| **智能撮合与僵尸房 GC** | `c2s_quick_match` / 30s 定时巡检 | 检索同规格 `WAITING` 房间优先合并真人；清理无真人残留房间 | 同步 `redisClient` 房间快照，广播 `s2c_rooms_updated` |
| **全游戏断线自动托管** | Socket `disconnect` 或 `c2s_toggle_trusteeship` | 标记座位 `disconnected / trusteeship = true`，挂载 1.2s AI 代理定时器 | 调用对应游戏 `BotEngine` 自动代打；重连后无缝恢复手动控制 |
| **账本记账与异步落盘** | 建房扣卡 / 领补给 / 牌局结算 | 写入内存状态与 `BeanLedger` 环形审计队列，触发 300ms 防抖写盘 | 写入 `.game-data.json.tmp` 后原子 `rename`，确保零阻塞零损坏 |
