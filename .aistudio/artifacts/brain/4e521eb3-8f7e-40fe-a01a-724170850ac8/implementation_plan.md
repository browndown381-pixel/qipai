# 全游戏选场子大厅商业化极简统一优化方案

针对斗地主、普洱麻将、抢庄牛牛、经典金花四大选场子大厅进行商业化视觉减法与一致性重构，彻底消除冗余文字说明、杂乱角标胶囊以及悬浮按钮遮挡卡片的问题，使各子大厅与主大厅保持高度统一的商业品质。

## User Review & Critical Decisions

> [!IMPORTANT]
> 以下设计决策已根据您的确认锁定，确认执行后将统一应用至全部四个选场子大厅（斗地主、麻将、牛牛、炸金花）：

- **场次卡片信息精简**：移除卡片左上角封顶角标（「40倍封顶」「推荐」等）、移除嵌套深色胶囊底框，每张场次卡片仅保留 **右上角在线人数 + 居中立体主题图 + 立体场次名称 + 简洁无框底分与准入豆数**。
- **顶部玩法切换栏极简化**：仅保留纯粹的单行玩法切换标签（如「看牌抢庄 / 通比牛牛 / 疯狂加倍」），**移除所有右上角微缩角标（「热门」「刺激」「百搭」等）、副标题描述行以及外部规则倍率按钮**。
- **彻底移除右下角悬浮「快速开局」按钮**：在所有选场子大厅中移除遮挡第 3、4 张场次卡片的悬浮 `QuickStartFab`，玩家直接点击对应场次卡片即可入局。

## 1. Overview & Core Concept

- **What It Does**：统一重构四大棋牌子大厅（斗地主、麻将、抢庄牛牛、炸金花）的选场界面，建立统一的商业棋牌选场视觉规范。
- **Target Audience / Persona**：追求清爽、直观、零视觉干扰选场体验的棋牌玩家。
- **Key Value**：消除卡片内多层胶囊堆叠与悬浮按钮遮挡，提升视觉呼吸感与触控选场效率。

---

## 2. User Experience & Visual Design

- **Key User Flows**：
  1. 玩家从主大厅点击任一游戏卡片进入对应选场子大厅。
  2. 顶部展示干净的 segmented 玩法切换栏（无角标、无副标题文字说明），点击即可平滑切换当前玩法模式。
  3. 画面主体展示 4 张色彩分明、等比协调的场次卡片（新手场 / 初级场 / 中级场 / 至尊场），无任何右下角悬浮按钮遮挡，点击任意场次卡片直接校验准入并进入牌桌。
- **Visual Identity & Theme**：
  - *Aesthetic Direction*：商业级极简轻奢棋牌大厅，遵循「Zero-Pill（去冗余胶囊）」与「单一视觉重心」原则。
  - *Color Palette & Mood*：延续明亮大厅背景，四档场次统一采用 **翡翠绿（新手）→ 皇家蓝（初级）→ 紫晶（中级）→ 鎏金赤红（至尊）** 渐变体系。
  - *Typography & Hierarchy*：场次标题采用高对比度立体描边展示字体（`clamp(1.25rem, 3.8vw, 1.8rem)`），底分与准入豆数采用等宽数字字体（`font-mono tabular-nums`），严禁多行折行。
  - *Component Styling & Layout*：桌面及横屏采用 4 列等宽单行网格（`grid-cols-4`），竖屏采用 2×2 对称网格（`grid-cols-2`），卡片内部去除多层嵌套圆角框，改用通透排版。
- **Interactive Feedback & Motion**：卡片点击与悬停仅使用 `transform` 与 `brightness`（150ms 响应），选场切换即时更新在线人数与入局模式。

## 3. Key Product Decisions & Trade-Offs

- **Decision 1：统一各子大厅场次卡片视觉组件**
  - *Chosen Approach*：将斗地主、麻将、牛牛、炸金花四大子大厅的场次卡片统一为相同的四档渐变与极简三段式结构（顶部在线人数 → 中部单一立体徽章与场次名+底分 → 底部简洁准入豆数）。
  - *Why*：消除原先麻将/金花自己拼贴三张牌、牛牛/斗地主使用不同胶囊样式导致的割裂感。
  - *Alternatives Considered*：各子大厅保留各自的复杂立绘拼贴（易造成视觉杂乱且字号不统一）。
- **Decision 2：移除右下角悬浮快速开局按钮（QuickStartFab）**
  - *Chosen Approach*：从全部选场子大厅移除悬浮在右下角的 `QuickStartFab`。
  - *Why*：在横屏及小屏视口下，右下角悬浮按钮直接遮盖了第 3、4 张场次卡片的准入豆数区域；场次卡片本身即为最直接的开局入口。

- **Data Model & State**：
  - 每个子大厅仅维护当前选中的 `activeMode` 状态，并结合玩家 `myBeans` 实时判断各场次 `canAfford`（准入状态）。
- **Interactive Component & State Mapping**：
  - 点击顶部纯净玩法标签 → 切换 `activeMode` 并播放轻触音效。
  - 点击任一场次卡片 → 若 `myBeans >= tier.minBeans` 则直接调用对应 `onQuickMatch*` 进入牌桌；若豆子不足则弹出 `InsufficientBeansModal` 引导免费补给或进入推荐场次。
