# 欢乐斗地主 & 炸金花 H5 商业版 (Card Game Platform)

面向 H5 横屏与移动端的高性能多人实时在线棋牌游戏平台。采用**服务端权威状态机**、**商业级拆牌博弈 AI 算法**与 **PixiJS v8** 牌桌渲染引擎，深度适配微信、抖音等移动端内置浏览器与各主流桌面端。

---

## 🌟 核心特性

- 🃏 **丰富玩法模式**
  - **斗地主**：经典玩法、不洗牌模式、赖子/癞子玩法（含多解释智能选型与压牌判定）。
  - **炸金花**：经典模式（常规大小对比）、特殊模式（豹子杀手 235）、看牌/闷牌翻倍博弈、全自动边池分账（Side Pot）计算。
  - **麻将算法**：34 维牌型引擎支持（标准胡、七对、十三幺、向听数估算、AI 出牌决策）。
- ⚙️ **服务端权威架构**
  - 核心逻辑运行于服务端状态机，杜绝客户端作弊与状态不同步。
  - 客户端即时预判 + 服务端二次裁决的双层状态保障。
  - 内置离线与托管机制（AFK 倒计时自动托管与状态恢复）。
- 🤖 **商业级 AI 算法**
  - 基于牌型权重的智能拆牌算法与首出/压牌博弈。
  - 动态对手建模与残局逼单策略（防守方 1 张牌时自动顶大单）。
- 🎨 **PixiJS v8 现代牌桌渲染**
  - 全新 PixiJS v8 架构，支持 WebGL/WebGPU 硬件加速与高帧率动画。
  - 自研 `AutoLandscapeContainer` 智能横屏适配（支持 90°/270° 虚拟旋转与触摸事件指针映射，无需强制系统横屏）。
  - 流畅的平滑发牌、理牌、出牌动效与筹码飞行粒子效果。
- 🧪 **健全的自动化测试套件**
  - 内置基于 Node.js 原生 Test Runner 的 34+ 自动化回归测试（规则逻辑、状态机、筹码守恒、托管生命周期等）。

## 🚀 快速上手

### 1. 安装依赖

```bash
npm install
```

### 2. 本地开发调试

启动集成了 Vite 开发服务器与 Socket.IO 网关的服务端：

```bash
npm run dev
```

启动后在浏览器打开：`http://localhost:3000`

### 3. 执行测试套件

运行全部斗地主与炸金花的服务端核心回归测试：

```bash
npm run test
```

亦可单独运行特定游戏测试：

```bash
npm run test:ddz   # 斗地主规则与 AI 测试
npm run test:zjh   # 炸金花分池与状态机测试
```

### 4. 类型检查与代码构建

```bash
# 类型检查
npm run lint

# 生产环境打包构建
npm run build
```

## 📱 移动端与横屏适配说明

本项目采用 **Contain-Fit 等比缩放 + 智能虚拟旋转** 机制：
- 在移动端竖屏状态下，系统将自动通过 `AutoLandscapeContainer` 虚拟旋转 90° 呈现横屏对局，同时重映射 PixiJS 触摸事件指针坐标。
- 保证玩家无需手动开启手机“自动旋转”开关即可获得沉浸式横屏体验。
